# 岗位六维能力评估系统使用手册

> 适用网址：`https://hfxwiu.top/`
>
> 管理员入口：`https://hfxwiu.top/#/admin`
>
> 管理员密码：`bluefocus2026`

## 一、系统简介

本系统用于岗位六维能力评估。管理员维护人员名单、创建评估批次、分配评分任务；评分人通过岗位链接填写匿名问卷；系统自动按评分层级汇总，生成六维能力图，并支持导出 PNG、PDF 和 Excel。

当前支持 7 个岗位：

| 职位ID | 职位名称 |
| --- | --- |
| sales | 销售 |
| business | 商务 |
| project-manager | 项目经理 |
| technical-delivery | 技术交付 |
| offline-operations | 线下运营 |
| ip-operations | IP运营 |
| content-distribution | 内容发行 |

## 二、管理员后台操作

### 1. 登录

1. 打开 `https://hfxwiu.top/#/admin`。
2. 输入管理员密码，点击“登录”。
3. 登录后可进入工作台。

### 2. 人员管理

进入“人员”页面后，可以：

- 新增人员：填写姓名、部门、职位，勾选“可被评”“可评分”。
- 批量导入：点击“批量导入 Excel/CSV”，选择填写好的模板文件。
- 全选、批量停用、批量启用、批量删除。

#### 人员导入模板字段

模板第一个工作表必须保持以下表头：

| 列 | 表头 | 必填 | 说明 |
| --- | --- | --- | --- |
| A | 姓名 | 是 | 人员姓名 |
| B | 部门 | 是 | 所在部门，姓名相同时可用更细的部门区分 |
| C | 职位ID | 是 | 从“职位对照表”中选择 |
| D | 可被评 | 是 | 填“是”或“否” |
| E | 可评分 | 是 | 填“是”或“否” |

说明：

- `可被评 = 是`：该人员可以出现在“被评估人”名单中。
- `可评分 = 是`：该人员可以作为评分人，被分配评价任务。
- 同一人姓名和部门相同时，请用更细的部门名称区分，避免任务匹配冲突。
- 系统支持 `.xlsx`、`.xls` 和 `.csv` 三种文件，推荐直接使用 `.xlsx` 模板。

### 3. 评估批次

进入“批次”页面：

1. 点击“创建”区域，填写：
   - 批次名称
   - 职位
   - 评估日期
   - 开放时间
   - 截止时间
2. 创建后批次为“草稿”状态，暂时不会出现在问卷页。
3. 点击批次进入详情页：
   - 添加被评估人。
   - 为每名被评估人添加评分任务，选择评分人及层级（上级/平级/下级）。
   - 检查每名被评估人都至少有一条评分任务。
4. 点击“开放批次”。
5. 到达开放时间后，该岗位的问卷链接才会显示此批次。

常用操作：

- 延长截止：开放状态时可修改截止时间。
- 关闭批次：停止提交并冻结结果。
- 重新开放：关闭后可重新开放。
- 归档：关闭后可归档，仅保留查询。
- 复制批次：复制为新的草稿批次。
- 导出 Excel/CSV：导出批次明细。

### 4. 评分结果

进入批次详情，点击某名被评估人的“查看”，可查看六维能力结果：

- 六维完整时，显示六维能力图。
- 可导出匿名 PNG 或 PDF。
- 可按批次导出 Excel/CSV 明细。

### 5. 题库管理

进入“题库”页面，可切换 7 个岗位查看和修改：

- 职位名称
- 岗位定位
- 评估周期
- 各维度名称、说明
- 每道题的题干、焦点及 A–E 选项

修改后点击“保存题库”即可。第一版只支持修改现有文字，不支持新增或删除题目、维度。

### 6. 修改密码

进入“修改密码”，输入当前密码和新密码。新密码至少 12 位。

## 三、评分人操作

### 1. 进入问卷

打开对应岗位链接，例如销售岗位：

`https://hfxwiu.top/#/q/sales`

其他岗位将 `/q/sales` 中的职位ID替换为对应职位ID即可。

### 2. 查找评价任务

1. 填写“姓名”和“所在部门”。
2. 点击“查找我的评价任务”。
3. 系统会列出预分配给该评分人的任务。
4. 点击“开始评价”进入问卷。

### 3. 填写问卷

- 问卷按 6 个维度分页，每个维度 5 题，共 30 题。
- 每题可选择 A–E，或“无法判断”。
- 同一浏览器会自动保存草稿，关闭页面后可用同一设备继续填写。
- 提交后不能自行修改；如需重填，请联系管理员作废原提交。

### 4. 提交

至少有一个维度达到 3 道 A–E 有效题即可提交。提交成功后仅显示“提交成功”，不会显示分数或被评估人结果。

## 四、计分规则

- A–E 对应 20、40、60、80、100 分。
- “无法判断”不计分。
- 单个评分人的某一维度至少 3 道 A–E 有效题才计入该维度。
- 同一层级先求平均分，再按上级 50%、平级 30%、下级 20% 权重归一。
- 只有六个维度都有有效样本时，才生成完整六维能力图和综合分。

## 五、常见问题

### 1. 导入后出现乱码

请直接使用系统提供的 `.xlsx` 模板；如使用 CSV，请保存为 UTF-8 编码。系统已兼容 UTF-8 和 GBK 编码。

### 2. 问卷提示“该岗位当前没有开放的评估批次”

原因是批次还没有开放，或开放时间还没到，或已经过期。请到管理员后台检查批次状态和开放/截止时间。

### 3. 找不到我的评价任务

请确认姓名、部门与管理员预分配时填写的内容一致；如果重名，请使用更细的部门名称。

### 4. 退出管理员后登录按钮一直显示“登录中”

请刷新页面。正常退出会返回首页。
