# 岗位六维能力图

一个纯前端的岗位能力评估小应用。支持按职位切换六维模型、上级/平级/下级多人评分、自动权重归一、历史记录对比和 PNG 导出。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd C:\Users\15213\Desktop\python\capability-radar-app
npm.cmd install
npm.cmd run dev
```

终端会显示本地访问地址，通常为 `http://localhost:5173`。

## 构建与检查

```powershell
npm.cmd run test:run
npm.cmd run build
npm.cmd run preview
```

生产文件生成在 `dist` 目录，可以部署到任意静态网站服务。

## 评分规则

- 原始评分范围为 0–100，最多一位小数，最终除以 20 转换成 5 分制。
- 同一层级有多人时，先对每项能力求该层级的平均分。
- 上级、平级、下级的基础权重分别为 50%、30%、20%。
- 完全没有有效评分人的层级不参与计算，其余层级按基础权重比例自动归一。
- 只有六项都完整有效的评分人才计入；完全空白的评分人自动忽略。

## 历史记录与隐私

- 只有点击“记录本次数据”并确认后，才会写入当前浏览器的 `localStorage`。
- 历史匹配条件为：姓名（去首尾空格）+ 部门（去首尾空格）+ 职位。
- 对比时只选择严格早于本次评估日期、且六维模型兼容的最近记录。
- 同一人、部门、职位和评估日期重复保存时，会询问是否覆盖。
- 清除浏览器网站数据会同时删除历史记录。
